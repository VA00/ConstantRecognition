# Calculators (Function Search Space)

This defines the search space for the mathematical expressions.

## Modules
- `standard_scientific`: Standard 36-button scientific calculator functions.
- `choose_from_list`: User-selected list of active functions.
- `drag_n_drop`: Custom node-based or structurally defined search space.
- `fire_everything`: Exhaustive search using all available mathematical operations.
- `eml`: the single binary operator eml(x, y) = exp(x) - ln(y) with the constant 1; the EML shortest-expression challenge and its solvers (`Competition.md`).
- `meijerg`: MeijerG and HypergeometricPFQ over rational parameters, one arithmetic operation on top (prototype, see `meijerg/README.md`).
